## 1.了解ACT
ACT是一个用C#编写的框架，要发挥它的能力，你应当尽可能学习一下C#的基础语法，如果您毫无编程语言学习基础，也可以根据后文给出的示例和通俗的教学进行尝试和学习。

#### C#基础语法
在每一个单句的结尾使用 `;` 作为结尾，就像这样：

```csharp
using system;
```

然后，在源码文件的开头使用 `using` 语句，引用需要的程序/库，提供功能支持。
> 在ACT插件的开发中，我们推荐你至少引入以下内容，如果您不了解这些内容的意思，请直接全盘复制并放到源码文件的开头。
```csharp
using System;
using System.IO;
using System.Linq;
using System.Windows.Forms;
using System.Reflection;
using System.Collections.Generic;
using System.Text;
using System.Text.RegularExpressions;
using Advanced_Combat_Tracker;
```

下面是一段简单的代码，我们将为你说明其中的意义。

```csharp
using System;
using System.Reflection;
using System.Windows.Forms;
using Advanced_Combat_Tracker;

[assembly: AssemblyTitle("My_ACT_Plugin")] // 一个好看的插件名字
[assembly: AssemblyDescription("没有描述")] // 插件的描述信息
[assembly: AssemblyVersion("1.0.1.1")] // 插件的版本号

namespace My_ACT_Plugin //命名空间，代表插件的国界线，同一个国界线声明的代码可以直接调用，超过国界线的情况下使用就需要 using 来处理外交关系
{
    public class ACT_Plugin_Example : IActPluginV1 // 定义你的插件模块名称
    {
        //Label 代表文本标签控件，任何一种数据/控件/变量类型开头的代码都代表声明一个对应类型的变量。
        Label statusLabel;    // 这是插件在插件列表中显示的文本。

        public void InitPlugin(TabPage pluginScreenSpace, Label pluginStatusText) // 初始化插件事件
        {
            Label lbl = new Label(); // 自定义的文本标签控件
            lbl.Location = new System.Drawing.Point(8, 8); // 设置自定义的文本标签位置，坐标 x 8, y 8
            lbl.AutoSize = true; // 自定义的文本标签 会根据显示的文本内容自动调整大小
            lbl.Text = "Hello, world!";
            pluginScreenSpace.Controls.Add(lbl); // 在你的插件UI中添加你刚刚自定义的文本标签控件
            ActGlobals.oFormActMain.OnCombatEnd += new CombatToggleEventDelegate(oFormActMain_OnCombatEnd); // 添加事件触发器 “战斗结束时”
            statusLabel = pluginStatusText; // 将插件列表中本插件的状态文本控件交给statusLabel处理
            statusLabel.Text = "插件初始化完成"; // 修改插件列表中这个插件显示的状态
        }

        void oFormActMain_OnCombatEnd(bool isImport, CombatToggleEventArgs encounterData) // “战斗结束时”触发器触发的事件
        {
            //string 代表一个字符串变量，
            string diplayString;
            diplayString = String.Format("{0} - 团伤:{1:0.00}", encounterData.encounter.Title, encounterData.encounter.DPS);
            MessageBox.Show(diplayString, "战斗结束！");
        }

        public void DeInitPlugin()  // 插件卸载时触发
        {
            ActGlobals.oFormActMain.OnCombatEnd -= oFormActMain_OnCombatEnd;
            statusLabel.Text = "插件已退出";
        }
    }
}
```
